# SideTask 1.3.3 发布验证

## 发布内容

本次打包包含源码提交 [8da21a4](https://github.com/LJger/sidetask/commit/8da21a4a6bd8a729dae2800a50729ac8da2eb7a9) 的窗口裁剪与拖动坐标修改：

- 收起时保留 WebView2 的完整窗口尺寸，通过原生窗口裁剪，只显示数字把手并接收该区域的输入。
- 原生拖动按可见区域计算位置，并同步调整跨显示器缩放时的坐标处理。
- 桌面检查脚本读取窗口的可见区域，用于检查贴边位置。

应用版本统一更新为 1.3.3；继续使用 v3 数据格式，保留透明度设置和此前的焦点切换、拖动请求超时恢复。

## 基础检查

- 本轮 41 个 JavaScript 文件语法检查通过，应用版本声明一致性检查通过。
- 对应功能代码已在提交 8da21a4 前通过 18 项 Rust 核心测试。
- Windows x64 Release 构建通过；使用现有 Tauri NSIS 模板和生产配置生成安装包。
- 安装版和便携版的文件及产品版本资源均为 1.3.3.0，并生成对应的 SHA-256 校验文件。

按本次约定，仅做简单代码检查和发布文件校验。Windows 实际绘制、鼠标拖动及安装升级流程由用户复验。

## 用户复验

先从托盘退出旧版，再运行 1.3.3。重点复验展开尚未完成时点击外部、再点图标能否正常展开，收起收尾是否闪烁，以及收起图标的拖动定位。
