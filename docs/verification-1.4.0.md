# SideTask 1.4.0 发布验证

## 发布内容

本次包含提交 `5a0ef6b` 的渲染性能优化、展开方式设置、动效与交互改进，以及本轮修正的列表 Enter 键误触完成问题。应用及浏览器预览版本统一为 1.4.0，继续使用 v3 数据格式。完整更新内容见 [发布说明](release-1.4.0.md)。

## 已完成检查

- 44 个 JavaScript 文件语法检查通过。
- 72 项 JavaScript 测试和 21 项 Rust 测试通过。
- 42 项浏览器界面测试通过，在 Linux Chromium 环境运行。发布前一条新增用例偶发失败：焦点停在完成按钮上按 Enter 会触发按钮默认点击而完成任务，而非打开详情；已修正为 Enter 打开任务、Space 保持完成，用例连续 6 次通过。
- Rust 格式检查通过。
- WSL 交叉构建（cargo-xwin、LLVM 14、NSIS 3.08）的 Windows x64 Release 可执行文件与安装包生成通过，确认 1.3.5 代码基线可正常链接与打包；正式发布文件改由 Windows 构建工作流原生生成。
