# SideTask 1.3.4 发布验证

## 发布内容

本次包含提交 `c4aabeb` 的日历操作、完成状态显示、面板透明度和桌面窗口处理改进。应用及浏览器预览版本统一为 1.3.4，继续使用 v3 数据格式。完整更新内容见 [发布说明](release-1.3.4.md)。

## 已完成检查

- 43 个 JavaScript 文件语法检查通过。
- 71 项 JavaScript 测试通过。
- 21 项 Rust 测试通过（1 项库测试、20 项核心集成测试）。
- 39 项浏览器界面测试通过；本轮在 Linux 上使用 Microsoft Edge 无头模式运行。
- Rust 格式检查通过，Linux 和 Windows x64 目标的 Clippy 检查通过，均按 `-D warnings` 执行。
- 前端生产资源生成通过。
- 使用 cargo-xwin 与 MSVC SDK 完成 Windows x64 Release 交叉构建，启用生产静态资源、LTO、体积优化及静态 C 运行库。

交叉链接时有微软 C 运行库 PDB 调试符号缺失警告，编译和链接成功，不影响发布程序运行。

## 验证范围

浏览器测试和交叉构建不等同于 Windows 原生桌面实测。Windows 上的安装升级、实际鼠标拖动、多显示器与 DPI、Edge 收藏夹和 Nexus 等程序的交互仍需在对应环境复验。

升级前请保存草稿并从托盘退出旧版。发布文件包括 Windows x64 安装版、便携版以及各自的 SHA-256 校验文件。
