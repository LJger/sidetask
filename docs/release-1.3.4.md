# 侧记 SideTask 1.3.4

## 更新内容

- 新增面板透明度设置，支持 0%–80% 即时预览并自动保存，与收起图标透明度独立调整。
- 默认显示已完成任务，日／周／月、全部任务和未安排视图可同时查看待办与完成记录；显示开关保存后与搜索共用。
- 点击周／月视图的空白区域可选择新增任务日期，保留已有草稿，完成、编辑与新增按钮保持独立操作。
- 窗口更新集中在 UI 线程执行，合并连续移动事件，对失败更新延迟重试，并调整焦点恢复方式。
- 增加可选窗口诊断日志，便于定位桌面交互问题。

## 下载与升级

- `SideTask-Setup-1.3.4-x64.exe`：Windows x64 安装版，推荐使用。
- `SideTask-Portable-1.3.4-x64.exe`：Windows x64 便携版。
- 同名 `.sha256` 文件用于核验下载文件。

升级前请保存草稿并从托盘退出旧版。继续使用 v3 数据格式和原有用户数据目录。安装包会在缺少 WebView2 时联网补装运行时。

## 验证范围

已通过 43 个 JavaScript 文件语法检查、71 项 JavaScript 测试、21 项 Rust 测试和 39 项浏览器界面测试。构建与文件校验的详细记录见 [1.3.4 验证记录](https://github.com/LJger/sidetask/blob/v1.3.4/docs/verification-1.3.4.md)。

Edge 收藏夹、Nexus 等受影响程序的偶发交互问题，仍需在对应 Windows 环境复验。
