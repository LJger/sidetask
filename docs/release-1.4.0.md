# 侧记 SideTask 1.4.0

## 更新内容

- 新增“展开方式”设置：滑入（默认）、淡入、弹出、展帘四种侧栏出现效果，设置面板附示意图，JS 与 Rust 两侧共同校验，均遵循系统“减少动态效果”。
- 动效：勾选画勾与弹动、行退出收拢、新增行高亮、详情面板滑入滑出，弹层、对话框与 Toast 增加过渡。
- 渲染性能：搜索只重绘列表与计数，对话框定位不再随按键执行，行级锁定与日历选日只做局部更新，分类标签改用索引，编辑器脏检查单次序列化。
- 界面：任务行圆角悬停、滚动条可见度调整，周期标签改为中文日期，清理死规则并合并重复样式。
- 交互：点击任务行空白处打开详情，Ctrl+Enter 保存详情，方向键与 Home／End 遍历列表，周期标签直接调用系统日期选择器，tooltip 仅保留在图标按钮。
- 修正列表键盘遍历时，焦点停在完成按钮上按 Enter 会误触完成的问题；Enter 现在打开该任务，Space 仍用于完成。

## 下载与升级

- `SideTask-Setup-1.4.0-x64.exe`：Windows x64 安装版，推荐使用。
- `SideTask-Portable-1.4.0-x64.exe`：Windows x64 便携版。
- 同名 `.sha256` 文件用于核验下载文件。

升级前请保存草稿并从托盘退出旧版。继续使用 v3 数据格式和原有用户数据目录，新增的展开方式设置使用默认值。安装包会在缺少 WebView2 时联网补装运行时。
