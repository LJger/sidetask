# SideTask 1.3.5 发布验证

## 发布内容

本次包含提交 `cb0939f` 的窗口边框修复与桌面测试调整。应用及浏览器预览版本统一为 1.3.5，继续使用 v3 数据格式。完整更新内容见 [发布说明](release-1.3.5.md)，修复原理与长测细节见 [窗口边框验证记录](verification-window-frame.md)。

## 已完成检查

- 44 个 JavaScript 文件语法检查通过。
- 71 项 JavaScript 测试和 21 项 Rust 测试通过。
- 39 项浏览器界面测试通过。
- Rust 格式检查通过，Windows x64 目标的 Clippy 检查通过。
- Windows x64 Release 原生构建和 NSIS 安装包生成通过，使用生产静态资源、LTO、体积优化及静态 C 运行库。
- 发布文件来自 [Windows 构建 35515539863](https://github.com/LJger/sidetask/actions/runs/35515539863)，构建提交为 `7e3bab2`，即标签 `v1.3.5`。
- 安装版和便携版的文件及产品版本资源均为 1.3.5，SHA-256 校验文件与产物一致。
- 构建工作流中的桌面自动化通过原生启动、保存、24 组收起展开、焦点与草稿保护、并发写入、失败保存恢复和重复任务撤销检查；失败前的原生探针确认窗口不带系统边框样式。
- 本地 Windows 11（10.0.26200）、WebView2 153.0.4234.48 上使用交叉构建完成原生边框回归长测：置顶开启、关闭各 40 轮展开收起（含动画中反转）、4 次焦点反转、2 次 Alt+F4；2,674 次窗口样式采样中系统边框样式出现 0 次。

## 验证范围

构建工作流中的桌面自动化在文件对话框自动化步骤失败：测试脚本在 CI 运行器的导出对话框中未能定位文件名输入控件，与 1.3.4 发布时记录的问题相同，属于测试脚本对系统对话框的适配问题，不影响应用产物。该步骤之前的原生检查全部通过。

本地长测使用独立应用标识与临时数据目录，与运行中的正式版并存。真实鼠标拖动、多显示器与 DPI、Windows 10、安装升级流程以及 Edge 收藏夹和 Nexus 等程序的交互未在本轮覆盖。

升级前请保存草稿并从托盘退出旧版。
