# SideTask 1.3.0 交接验证记录

交接日期：2026-09-13。按用户要求停止后续测试，交由用户复验。

## 已完成

- 迁移为 Tauri 2 / Rust / WebView2，生成 Windows x64 安装版与便携版。
- 收起把手仅显示数量，40×40 DIP；整块可拖动，松手吸附最近边缘；失焦立即开始短动画，保留草稿和弹窗保护。
- 65 项 JavaScript 单元测试、14 项 Rust 测试通过；Rust 测试包含 26 组与原 JavaScript 模型的业务契约对照。28 项浏览器测试通过。
- Windows 11（10.0.26200.8655）真实双屏：主屏 100%、副屏 150% 的四边鼠标拖动、跨屏移动、点击展开通过。
- 100%、125%、150%、200% 强制 WebView2 / 布局缩放检查通过：每档 24 组把手显示与点击，以及原生鼠标拖动、失焦收起、草稿保护、并发保存、失败后重试、重复任务撤销、隐藏启动、重启与提醒去重。
- 强制缩放是测试模拟，不等同于逐档修改 Windows 显示设置。上述混合 DPI 另用实际系统设置测试。
- 首次迁移保留 tasks.pre-tauri.json，沿用原数据目录和 v3 格式；仍保留 v1/v2 迁移、原始备份、损坏恢复、未来版本拒绝覆盖。
- 安装器已改为发现运行中的应用就退出，不强制杀进程；便携版启动也会检查仍运行的旧版。

## 交给用户复验

- 最终原生导入／导出对话框流程，以及安装、卸载与开机启动的完整流程。
- 真实系统通知横幅和点击定位；自动化已验证后台调度、持久化认领、去重与界面通知。
- 缺少 WebView2 的全新环境、Windows 10。安装器配置为按需在线补装 WebView2，未将运行时打进安装包。
- 当前 Windows 旧版仍在运行，全局快捷键被占用的提示正常；退出旧版后需复验快捷键。
