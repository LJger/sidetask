# 侧记 SideTask 1.4.1

## 更新内容

- 调整任务列表、日历、详情和弹层的布局、间距、圆角与层次，统一四套主题的配色与控件样式。
- 重新组织设置页，按外观、窗口行为和数据管理分组，优化主题、展开方式和透明度控件。
- 日／周／月视图与分类管理标签增加滑动选中指示，切换视图、日期和详情时增加方向过渡，弹层从触发位置展开；遵循系统“减少动态效果”设置。
- 调整 Windows 侧栏的工具窗口样式，处理收起后透明区域可能干扰 Edge、WebView2 等 Chromium 程序绘制的问题，并在窗口样式更新时保持该设置。具体程序中的实际效果仍需实机复验。
- 合并重复的界面样式，移除独立的 `workspace.css`。

## 下载与升级

- `SideTask-Setup-1.4.1-x64.exe`：Windows x64 安装版，推荐使用。
- `SideTask-Portable-1.4.1-x64.exe`：Windows x64 便携版。
- 同名 `.sha256` 文件用于核验下载文件。

升级前请保存草稿并从托盘退出旧版。继续使用 v3 数据格式和原有用户数据目录。安装包会在缺少 WebView2 时联网补装运行时。
