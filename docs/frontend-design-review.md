侧记 SideTask：frontend-design 复查
检查日期：2026-09-08

本报告记录 1.1 版本的检查依据和设计草案。1.2 已结合后续需求加入四边停靠、主题与日历；当前行为见 README，实际验证范围见 verification.md。

本次按 frontend-design 的产品定位、排版、结构语义、交互反馈和界面文案原则复查。侧记的主要场景是在其他工作之间展开窄侧栏，记录、查看和处理任务。设计重点应放在中文任务的可读性、稳定的操作位置，以及边缘把手和展开动作形成的辨识度。

依据为当前源码、docs/preview.png、docs/details.png、docs/categories.png，以及直接运行的颜色对比度计算和任务筛选场景。浏览器在沙箱外启动仍因缺少 libnspr4.so 失败，本次没有取得新的运行截图。下列布局建议是设计草案；涉及拥挤程度的结论仍需在实际窗口中复核。

**第一遍设计草案**

方向：让边缘把手与横向展开动作承担产品辨识度，内容区呈现一张便于连续扫读的任务清单。界面默认左对齐，日期、时间和数量使用稳定对齐；当前选择和异常状态有明确强调。

候选基础色如下，尚未应用到产品。背景向中性收敛，让松绿色主要服务操作与选中状态。

| 名称 | 色值 | 用途 |
| --- | --- | --- |
| 面板底色 | #F7F8FA | 面板与安静的外围背景 |
| 编辑底色 | #FFFFFF | 输入区和浮层 |
| 正文色 | #242424 | 任务名称与主要文字 |
| 辅助文字 | #5D6268 | 日期、分组和补充说明 |
| 松绿强调 | #285B46 | 边缘把手、主按钮、选中状态 |
| 逾期提示 | #A34732 | 逾期、失败或危险操作，结合文字或图标表达 |

辅助文字在候选面板底色上的对比度约 5.79:1，松绿在白底上约 7.85:1，逾期提示在白底上约 5.99:1。交互状态和深色模式需要单独配色及验证。

字体采用中文界面字体体系：Windows 优先 Microsoft YaHei UI，其他环境使用相应 CJK 系统字体回退。标题、正文和辅助信息共享同一体系；字号建议以 18px 页面标题、14px 任务标题、12px 控件文字、11px 必要辅助信息为起点。主任务行高约 1.5–1.6；时间和数量使用等宽数字。具体中文断行和系统缩放需要在目标 Windows 环境验证。

**第二遍对照产品定位复核**

推荐方案 B。它把阅读空间和视觉强调更多分配给任务名称与执行状态，适合在其他工作之间短暂展开查看的场景。实施时要保证任务的点击范围仍然清楚，普通行采用留白、轻分隔和悬停反馈区分。

上一轮的“统一圆角”细化为统一层级规则：面板作为外壳可保持约 14–16px，输入控件约 6–8px，普通任务行根据状态决定是否需要背景与边界。

配色辨识度集中在松绿把手与主操作。系统中文字体服务持续阅读，开合动效说明窗口的位置变化。详情页继续复用侧栏空间，按“任务内容、安排、子任务、补充信息”的顺序组织。

搜索范围先做到可见并可切换，是否默认全局可在实际使用后决定。新增日期应尊重已有草稿。自然语言输入、多主题、窗口密度等能力安排在基础交互与阅读问题之后。
