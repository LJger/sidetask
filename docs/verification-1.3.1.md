# SideTask 1.3.1 基础验证

## 变更

- 在“设置 → 外观”增加收起图标透明度，默认 20%，范围 0%–80%。自动保存；悬停、键盘聚焦和拖动时恢复不透明。
- 数字把手改为按实际窗口尺寸独立定位，窗口缩小和页面收到状态通知之间也能保持在可见区域。
- 连续反向操作接续当前动画进度；重复通知不重启动画，过期回执和阶段回退被忽略。未准备完成时的完成回执不会提前改变窗口尺寸，超时恢复仍保留。
- 沿用 v3 数据格式；旧配置自动补充透明度默认值。
- 修正完整静态 CRT 设置与 Tauri 构建工具默认链接参数的冲突，保持原有运行库链接方式。

## 已完成的基础检查

- JavaScript 语法检查通过，66 项 JavaScript 单元测试通过。
- 15 项 Rust 核心测试通过，包括设置校验、保存失败回退、重启恢复，以及 26 组浏览器／Rust 业务契约对照。
- 6 项关键浏览器功能测试通过：透明度保存、交互和失败回退；模拟原生窗口先缩小、状态通知后到达时的把手位置和点击命中；21 次鼠标连点；重复及过期通知；数字把手拖动；失焦收起和重新聚焦取消动画。
- Windows x64 发布构建通过，安装包与便携包的 PE 版本资源均为 1.3.1.0。使用现有 Tauri 安装器模板及当前生产配置生成 NSIS 安装包。

浏览器测试中的窗口缩小是可控模拟，能覆盖页面定位与事件时序问题；它不代表已验证 Windows 桌面合成器的实际绘制。

## 用户复验

按本次要求，其余测试交由用户进行，重点确认 Windows 1.3.1 收起快结束时不再出现整个小块短暂消失，以及日常快速连点后图标仍可正常使用。多显示器、不同缩放、长时间使用和安装流程未在本轮执行。

升级时先从托盘退出旧版，再运行 1.3.1。安装版与便携版继续使用原有本地数据目录。
